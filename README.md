# 🐱 CatGame Foundry // Universal Storefront

Modern, neobrutalist cyber-terminal storefront for **CatGame**, developer skills, and client prototypes. Built for zero-backend static deployment on **Vercel** with Discord ticket fulfillment.

## 🚀 Live Demo & Deployment
- **Platform**: Vercel (Static / Zero-Config)
- **Engine**: Pure Vanilla JS, Modern CSS tokens, HTML5
- **Fulfillment**: Discord Server Tickets (`#tickets`)

## 📦 Featured Units & Catalog
1. **CatGame Flagship Mod**: Undetected Minecraft Fabric 1.21.11 Chat Game Auto-Solver with 2,466+ word dictionary, sub-second math/gap/unscramble solvers, and 20s/10s predictive radar warnings.
   - 🥉 **Iron Tier**: ₹80 (Lifetime Permanent), 4.0s delay, 1 device.
   - 🥇 **Gold Tier**: ₹20/wk (or ₹70/mo), 2.5s delay (down to 2.0s), 2 devices.
   - 💎 **Diamond Tier**: ₹40/wk (or ₹140/mo), 0.8s near-instant delay (down to 0.1s), 5 devices.
2. **Developer & Agentic Skills**: Minecraft Modding Agent Skill, Neobrutalism Design System, Typography Mastery.
3. **Prototypes & Clients**: CatClient 1.21.11, PocketVPS, CatBot.

## 🛠️ Local Development & Deployment
```bash
# Test locally
python3 -m http.server 3000

# Deploy with Vercel CLI
vercel deploy --prod
```
